📚 How to Use & Algorithm Notes

Running the Project

Open index.html in any modern browser — no server or build step required.

Algorithm Steps → UI Mapping

  1. Initialise: Source gets dist=0, all others dist=∞. Priority queue seeded with source.
  2. Extract-Min: Node with smallest distance is "settled" — highlighted in amber. Marked in Settled Set tab.
  3. Relax Edges: Each neighbour is checked. If dist[u] + w(u,v) < dist[v] then dist[v] and pred[v] are updated (green flash). Otherwise the edge is grey.
  4. Repeat: Until queue is empty. Each iteration = one "step" in the UI.
  5. Tie-break rule: When two nodes have equal priority, the one whose name comes first alphabetically is settled first.

Edge Cases

  • Cost ≤ 0 is rejected with a warning.
  • Disconnected nodes show ∞.
  • Ties are broken alphabetically (lower node name wins).

Verification

A brute-force simple-path enumerator checks every path from source to each destination and confirms Dijkstra's output matches the true minimum. Badge shows PASS/FAIL.
